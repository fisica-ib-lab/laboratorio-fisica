# Laboratorio de Física IB

Simulaciones interactivas para Física del Programa del Diploma (NM y NS), en español.

Sitio: https://fisica-ib-lab.github.io/laboratorio-fisica/

- `index.html` — portal con los temas A–E.
- `catalogo.js` — lista de simulaciones (añadir una = carpeta en `sims/` + una entrada).
- `comun/` — estilos comunes y cinemática exacta por tramos.
- `sims/A.1-tres-graficas/` — «Un movimiento, tres gráficas»: Explorar (3 niveles), Construir y Practicar (13 tipos de ejercicio).
- `pruebas/` — verificación de la física y de los ejercicios: `node pruebas/verificar-cinematica.js` y `node pruebas/verificar-ejercicios.js`.
- `fuentes/` — letra Carlito (licencia SIL OFL 1.1), compatible con Calibri.
